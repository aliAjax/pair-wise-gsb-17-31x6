# hxwl-03 测斜观测台

基坑测斜（活动式测斜仪）现场记录与判读面板：替代纸表誊抄，把正反行程差异、缺测区间和位移推算分开处理，现场即可判断读数能不能用。

## 现场工作流

1. **每孔先设基准**：建档时确定孔深、测点间距（默认 0.5m）、正反行程允差、累计位移与变化速率的关注/预警阈值，再录一轮基准观测。
2. **按深度录入**：自孔底向孔口逐点录入正行程（下放）、反行程（提升）读数和纸表累计位移；实时显示 `|正+反|` 偏差与按基准推算的累计位移，支持一键誊填，纸表值与推算值不一致会标出。
3. **判异先入待复核区**：正反偏差超限，或正/反读数缺项、缺少相邻测点导致区间中断，测点暂不进入正式曲线；现场写明复核原因后，选择“复核采用”或“弃用/登记缺测”。
4. **正式曲线**：仅绘制无判异及复核采用的测点，以孔底为不动点自下而上逐测段累加；断链区间用红色虚线标出。
5. **再次观测**：累计位移对照基准、变化速率（mm/d）对照上次结果，逐点与整孔给出**稳定 / 关注 / 预警**。
6. **孔号切换**：全部数据与复核结论存于本机 localStorage，切换孔号再回来处理结果仍在。

内置三个示例孔：CX-08（稳定→关注→预警全流程，含待复核/已采用/已弃用示例）、CX-11（缺测区间中断）、CX-16（尚未设基准）。清空浏览器本地存储即可恢复示例。

## 分层结构（数据整理 / 校验规则 / 界面分离）

```
src/inclino/
  types.ts    领域模型（孔配置、轮次、测点读数、复核结论）
  math.ts     纯数值工具（深度序列、读数换算）
  rules.ts    校验规则（正反偏差、缺测/缺相邻测点、测点状态）— 纯函数
  curves.ts   数据整理（累计位移推算、正式曲线、稳定/关注/预警判定）— 纯函数
  store.ts    数据操作（纯函数）+ localStorage 持久化
  seed.ts     示例数据
src/components/  界面（录入表 / 待复核区 / SVG 曲线 / 状态横幅 / 侧栏）
src/App.tsx      组装
```

## 判定口径

- 单测段倾斜量 = `(正行程读数 − 反行程读数) / 2`（正反各测一次抵消零偏）。
- 正反行程偏差 = `|正 + 反|`，超过该孔允差即判异（零偏异常或重测误差）。
- 位移增量 = 本次测段倾斜量 − 基准测段倾斜量；累计位移自孔底 0 起逐段累加，缺测/弃用/待复核点断链。
- 关注/预警：`|累计位移|` 或 `|较上次速率|` 达到该孔阈值即取对应级别，整孔取最差测点。
