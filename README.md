# hxwl-03 岩土测斜现场观测台

测斜观测（inclinometer）现场记录与校验面板：替代纸表誊抄，在现场直接判断读数能否使用。

## 现场工作流

1. **先设基准**：每个测斜孔先建立基准测次，由孔深与点距确定测点序列；正反和偏差、位移/速率阈值按孔可调。
2. **按深度录入**：逐点录入正行程、反行程读数与累计位移（mm），页面实时给出正反和。
3. **自动分流待复核**：
   - 正/反行程任一缺测 → 标记缺测区间；
   - 相邻测点缺测 → 标记缺少积分基准；
   - `|正程 + 反程 − 本测次典型值| > 限值` → 标记正反行程差异超限。
   命中任一规则的测点进入「待复核区」，**必须写明原因后采纳**才进入正式曲线；也可写明原因退回（留痕，不参与曲线与判定）。
4. **复测判定**：再次观测时逐点对照基准（累计位移）与上次复测（位移速率 mm/d），给出稳定 / 关注 / 预警，全孔取最差等级。
5. **正式曲线**：SVG 深度—位移曲线只连接已准入测点，缺测区间断线不跨越；可切换相对基准 / 原始累计、显示历次测次。
6. **切换孔号保留结果**：数据存于浏览器 `localStorage`，切走再回来，录入与复核结论都在；支持一键恢复演示数据。

## 分层结构（数据、规则、界面分离，无新增依赖）

```
src/
  domain/            纯领域层，无 React 依赖，可单测
    types.ts         孔/测次/测点/阈值/状态模型
    rules.ts         校验规则、正式曲线准入、状态判定等纯函数
    seed.ts          确定性演示数据（含超限与缺测场景）
    storage.ts       localStorage 读写与版本回退
  state/
    store.ts         状态变更动作与派生数据（useBenchStore）
  components/        纯界面层：Sidebar / Baseline / Entry / Review / Curve
```

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103。`npm run build` 可做生产构建（含 TypeScript 检查）。

## 演示孔

- **CX-01**：4 个测次，历史含正反差异超限（已退回）与缺测区间（已采纳相邻点）；最新复测 10m 处待复核，整体位移预警。
- **CX-02**：基准 + 一次复测，稳定。
- **CX-03**：仅基准，待复测。
- **CX-04**：新建孔，演示设置基准流程。
